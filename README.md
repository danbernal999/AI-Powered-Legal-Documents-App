# AI Powered Legal Documents App

Proyecto: AI-Powered-Legal-Documents-App

Resumen
- Aplicación para gestionar, generar y revisar documentos legales asistida por IA. Contiene backend en Go y frontend en Next.js.

Enlaces rápidos
- Configuración: [SETUP.md](SETUP.md)
- Pruebas y ejemplos de API: [TESTS.md](TESTS.md)
- Archivos originales: `archive/md/`

1. Introducción
Una breve descripción del propósito del repositorio, arquitectura general y componentes principales (backend Go, frontend Next.js, Firebase para auth/storage, y servicios de IA).

2. Estado del repositorio
Los archivos auxiliares y notas técnicas originales han sido movidos a `archive/md/` para mantener este `README` conciso y profesional.

3. Instalación (resumen)
- Requisitos: Go, Node.js, Docker (opcional), Firebase CLI
- Pasos básicos:
  1. Consultar [SETUP.md](SETUP.md) para la instalación completa.
  2. Configurar credenciales en `firebase-credentials.json`.
  3. Construir y ejecutar backend y frontend según instrucciones de `SETUP.md`.

4. Arquitectura
Resumen de alto nivel: microservicio backend en Go con rutas en `backend/cmd`, migraciones en `backend/migrations`, y frontend en `frontend/` usando Next.js y Tailwind.

5. Uso y pruebas
